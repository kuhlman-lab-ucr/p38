# RNAseq Analysis Pipeline

This repository contains scripts, notes, and data for running RNAseq Analysis.
---

# 1. Overview

This repository contains the analysis pipeline used for RNAseq Analysis.  
It includes:

1. DE_analysis.m — Matlab script for analysis
2. gene_count2.xlsx — An Excel file containing gene counts obtained from RNAseq data
3. RNAseq_workspace.mat — the Matlab workspace containing the output of DE_analysis.m being executed upon gene_count2.xlsx


---

# 2. Requirements

You need:

- Matlab — code was written and executed on Matlab R2025b
  
---

# 3. Installation

Code provided is not an executable and does not require installation. Load and execute code in Matlab
 
---


# 4. Running Matlab code

Change the path for gene_count2.xlsx to that on your local machine, and execute code.

---


# 5. RNAsequencing Data

Raw RNA sequencing data are available at the Sequence Read Archive, BioProject PRJNA1225323. Gene counts (identical to that found in gene_counts2.xlsx) is available at the Gene Expression Omnibus (GSE289999).
