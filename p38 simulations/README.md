# Biochemical Resonance Simulations

This repository contains scripts and data for running Biochemical Resonance Simulations in Mathematica.
---

# 1. Overview

This repository contains the analysis pipeline used for biochemical resonance simulations.  
It includes:

1. simulation_ensemble_data.nb — Mathematica Notebook containing simulation code
2. p38_f_0xx — Pre-run output of simulations of p38 oscillations driven at the indicated frequency that can be used as input for simulations of resonance selectivity.

---

# 2. Requirements

You need:

- Mathematica — code was written and executed on Mathematica 14.2
  
---

# 3. Installation

Code provided is not an executable and does not require installation. Load and execute code in Mathematica
 
---


# 4. Running Mathematica code

Load simulation_ensemble_data.nb into the Mathematica workspace. Change the path to load the desired p38 simulation output, and execute code blocks in Mathematica.
